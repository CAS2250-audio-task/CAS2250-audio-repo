# 다음 compact 증강 실험을 위한 기존 기록

## 현재 적용 중인 정책

대상: compact-local 및compact-acoustic-local-spk03-e1000. 입력mono16kHz,1.5초,64mel. 현재는 다음두종류만 사용한다.

| 종류 | 실제 설정 | 변형 생성 |
|---|---|---|
| 포먼트 | 명령어에p0.5,비율log-uniform[1/1.1,1.1] | 녹음당고정2변형에서선택 |
| 추가소음 | noisy view에서p1.0,SNR uniform[-5,20]dB | 훈련6소음 중선택,매epoch새1.5초crop/SNR |

포먼트는Praat Change gender 설정으로 피치·길이를 유지하도록 변형하고 RMS를맞추며peak0.99제한. silence에는포먼트를적용하지 않는다. 소음은silence에도적용하며 레벨기준은train명령어의원본full-clip RMS중앙값이다. 명령어의SNR도발화구간이아닌full-clip파워기준이다.

순서: 원본→선택적포먼트→reference view / 추가소음view. 같은포먼트변형을공유한두view모두CE에사용하며추가SupCon을적용한다. reference는추가잡음합성전녹음이지무잡음정답음원이아니다. noisy view의p1.0을모든view에잡음을넣는다는뜻으로해석하지않는다. 기존compact의단일view CE비교에서는소음p0.5였다.

속도변화·피치변화·SpecAugment·VAD자르기는현재OFF. 현재보조특징set3는증강이아니라입력경로다. noisy view의보조특징은실제로혼합된파형에서추출한다. 훈련/평가소음원본을분리하고,평가는원본및고정0dB8소음×3draw다.

## 이전 증강 종류와 세부

| 정책 | 이전에실행한설정 | 주의 |
|---|---|---|
| 소음혼합 | p0.5,SNR[-5,20]dB,분리된훈련6원본,온라인crop | 현재paired noisy view는p1.0 |
| 속도 | p0.5,피치유지0.9~1.1배,파일당2고정변형 | 검수비패딩구간보호;넘치는감속은skip,가속부족분0패딩 |
| SpecAugment | p0.5,시간20~50ms,주파수3~5/80mel bins | 현재64mel/정규화로옮길때폭·무음값재설계필요 |
| 파일내피치 | p0.5,4anchor[0,±1,±1,0]반음,2고정변형 | 내부anchor차이≥0.35,포먼트보존,지연보정 |
| 포먼트 | p0.5,log-uniform[1/1.1,1.1],2고정변형 | 현재계승한정책 |
| 발화구간피치 | p0.5,파일당8PCHIP곡선,최대변화1/1.5/2/2.5반음,32반음/초제한 | 자동VAD구간안만변형,20ms crossfade,정답구간아님 |

포먼트와피치는다르다. 포먼트는음색/공명특성변형을,피치는기본주파수/억양변화를겨냥한설정이다. 목표를유지하도록설계했어도출력음질·발음보존은확인해야한다. 고정2/8변형은매epoch무한히새파형을만드는증강과다르다.

## 완료 결과1: 사전학습 Conformer,4fold,10epoch

최고checkpoint는원본validation F1로선택했고소음은별도평가했다.

| 훈련조건 | 원본F1 | 0dB F1 |
|---|---:|---:|
| 무증강 | 99.32% | 72.57% |
| 속도+마스킹 | 99.20% | 73.09% |
| 소음 | 99.20% | 78.47% |
| 속도+마스킹+소음 | 98.98% | 78.05% |

소음혼합은무증강대비0dB+5.90%p. 속도+마스킹을소음에추가한이득은없었다. 속도와마스킹의단독효과는이표에서분리할수없다.

## 완료 결과2: Conformer 장기계열,4fold,100epoch

동일noise epoch10 LAST에서11~100까지이어학습. 기존소음p0.5는공통이다. Dropout0.2선택후A=마스킹+속도+파일내피치,B=포먼트를비교했다. 최고선택은고정0dB draw0,표는최종3draw개발평균F1이다.

| 조건 | 0dB F1 |
|---|---:|
| 이전기준,dropout0.1 | 89.75% |
| dropout0.2 | 90.67% |
| dropout0.2+A | 90.68% |
| dropout0.2+B | 91.30% |
| dropout0.2+A+B | 90.85% |

같은dropout0.2기준에서A+0.02%p,B+0.63%p,A+B+0.19%p. 당시채택기준평균F1+0.5%p/최저화자하락1%p이내를통과한것은B뿐이었다. A묶음결과로피치/속도/마스킹단독효과를판정하지않는다. 현재compact포먼트정책은이계열의설정을계승하지만다른모델에서도효과가보장되는것은아니다.

## 완료 결과3: 더다양한발화구간피치

기존소음+약한포먼트+dropout0.2에서발화구간안에다양한피치곡선을추가했다. Conformer4fold/100epoch,같은epoch10출발이다.

| 조건 | 0dB F1 |
|---|---:|
| 기존기준 | 91.30% |
| 발화구간피치추가 | 90.84% |
| VAD어텐션게이트만 | 91.64% |
| 게이트+피치 | 91.30% |

피치추가는개선되지않았다. 게이트는증강이아니라입력의시간가중치변경이며,raw최고였지만당시+0.5%p채택기준을넘지않았다. 이피치정책은앞의약한4anchor정책과별개다.

## 증강과구분할것

Dropout/weight decay는정규화,보조음향은입력경로,대조학습은손실목표,DFN3는전처리필터,VAD게이트는모델의가중방식이다. 위실험에서함께등장하지만같은증강항목으로집계하지않는다.

## 다음compact증강비교에서유지할원칙

현재소음+포먼트/local/보조ON조건을기준으로,구조·loss·LR·batch를같이바꾸지않고정책을분리해비교한다. 과거결과만으로속도/마스킹/피치효과를확정하지않는다. 보조OFF결과를보조ON증강실험의동일조건대조군으로삼지않는다.

마스킹을추가한다면같은시간구간의보조값/availability에도동일마스크를적용해경로우회를막는다. 원시Hz에0만넣는방식과정규화후0을넣는방식은다르므로구현을명시한다. 주파수마스킹은mel에만적용할때보조경로에남는정보가있음을기록한다. 파형속도/피치변형은변형된파형에서보조를재추출한다.

특히정지↔전진/후진같은혼동을보려면큰시간마스크나무리한변형이구별구간을가리지않는지확인한다. 원본·소음정답률,명령어10종F1,silence F1,잡음단독오반응과파일별회복/악화를함께비교한다. 같은원본의변형들은같은fold에묶고validation/test는훈련증강에사용하지않는다.

이문서는기존실행정리이며새증강학습은시작하지않았다. 현재보조set3학습의설정/소스를변경하지않았다.
