# 다음 세 축 실험 리마인드

기존 기록을 재확인한 정리다. 검출기 학습과 세로 어텐션은 별도 작업으로 두고 이 문서에서 제외한다.
여기에 적힌 새 원본 수집·연속 증강·추가 보조 실험은 이번 정리 과정에서 시작하지 않았다.

## 현재 공통 기준

- 기존 compact 학습은 약한 포먼트 p0.5, 비율[1/1.1,1.1], 원본당 고정2변형을 사용한다.
- reference는 추가잡음 합성 전 녹음이며 완전한 clean 보장은 없다. reference/noisy 두 view에 CE, 같은 명령어 positive에0.1 SupCon을 적용한다.
- noisy view에는 훈련6소음 중 하나를 SNR[-5,20]dB로 매epoch 새로 섞는다. silence에도 소음을 섞는다.
- 피치·속도·SpecAugment·연속 화자 프로파일은 현재 기본 훈련에서 OFF다.
- 새 정책을 비교할 때 모델·loss·학습 예산·검증 분할은 고정한다. 소음/화자 증강/보조 입력을 동시에 바꾸지 않는다.
- 기존 화자03 개발 결과는 여러 번 선택에 사용됐다. 새 독립 환경 원본을 최종 확인용으로 별도 남긴다.

## 1. 소음 다양성: crop보다 독립 원본 확대

실제 훈련 source manifest는6원본, 약130분이다.

| 종류 | 원본 |
|---|---|
| 도로/교통 | bus, traffic |
| 군중 | canteen, square |
| 기계 | mixer, pump |

긴 파일에서 매번 다른crop을 뽑지만 독립 환경은6개라는 한계가 남는다.

다음 작업:

1. 장소·기기·녹음회차가 다른 환경 원본을 확보한다. 주요 실패인 군중 말소리·불규칙 소음·기계 소음을 포함한다.
2. 기존 평가8소음 원본을 훈련으로 이동하지 않는다. 새 자료도 원본/세션 단위로 train 및 보류 환경으로 분리한다.
3. 원본/준비파일 hash와 출처를 기록한다. 카테고리·원본별 sampling도 기록해 자료 수 증가가 한 종류 쏠림이 되지 않게 한다.
4. 먼저 기존6원본 대 원본 확대를 비교한다. 기존 SNR·포먼트·구조·loss는 유지한다.
5. 약한 잔향/RIR, 마이크EQ, gain, codec은 원본 확대 효과를 본 뒤 각각 추가한다. 음성만 gain을 바꾸는 것은 전체 혼합 gain과 SNR 효과가 다르다.

기록에 조사 후보로 DNS noise, OpenSLR28 RIR/noise, MUSAN이 있다. 이번 정리에서 새 다운로드나 사용 가능성 재검증은 하지 않았다.

## 2. 증강 다양성: 파일 기본값과 작은 연속 변화를 분리

사용자 의도는 한 파일 안을 급격히 뒤섞기보다, 파일마다 다른 목소리 기본값을 주고 그 안에서 완만하게 변화시키는 방식이다.

| 요소 | 파일 전체 기본값 후보 | 파일 내부 변화 후보 |
|---|---|---|
| 피치 | 예: -2~+2반음 offset | 기본값 주변±0.2~0.4반음의 완만한 곡선 |
| 포먼트 | 우선 기존 총범위0.909~1.1 유지 | 기본비율 주변 약±1%, 총범위 안 |
| 속도 | 예:0.97~1.03배 | 주변±1%, 총0.95~1.05 안 |

위 숫자는 기존 설계 문서의 초기 후보이며 검증된 최적값이 아니다. 속도 변화는 파일 간·파일 안 모두 작게 유지한다.
2~4개의 완만한 제어점, 최대기울기 제한, 변형하지 않는 샘플을 포함하고 매프레임 독립 난수나 강제 최소 변화량은 쓰지 않는다.
양끝을 무조건 원래 목소리로 돌리지 않고 파일 기본 스타일을 유지한다.

실행을 분리한다면:

1. A0: 기존 고정2변형 포먼트 기준.
2. A1: 파일별 기본 프로파일 다양화. 피치/포먼트/약한 속도를 제어하되 파일 안 곡선은 아직 추가하지 않는다.
3. A2: A1에 작고 완만한 파일 내부 변화 추가.
4. A3: 채택한 프로파일에 약한 EQ/에너지 변화만 추가.
5. 마스킹은 별도 비교. 우선 reference를 보존하고 noisy view에만 시간/주파수 soft mask를 각각 시험한다.

같은 화자 프로파일을 reference/noisy에 공유하고 소음만 다르게 하는 것이 초기안이다.
서로 다른 가상 화자를 positive로 묶는 것은 별도 후속 실험이다.

마스킹의 기록된 초기 후보는 p0.25, 시간1~2프레임 또는64mel 중1~2band다. soft/hard와 시간/주파수를 분리한다.
soft는 선형 power 감쇠 후 log/정규화를 적용한다. logmel 값에 단순히0.5를 곱하는 것과 다르다.
재시작의 앞부분 등 구별 단서를 완전히 없애면 reference가 남아 있어도 masked view의 정답 정보가 복원되지는 않는다.

구현 전 확인:

- 기존 Praat 상수 formant ratio 호출만으로 시간가변 포먼트를 만들 수는 없다. 시간가변 포락선 변형은 아직 구현·검증되지 않았다.
- 기존 피치/속도 코드를 재사용할 때도 지연·끝음절 잘림·길이·peak/RMS·경계 artifact와 실제 F0/포먼트 변화를 확인한다.
- 먼저 여러 명령어/화자의 소수 예시를 만들어 청취한다. 피치/포먼트 측정 성공만으로 발음 보존을 판정하지 않는다.
- 약한 발성 근사는 EQ/에너지/필요시 작은 억양 변형 후보다. 단순 음량 감소, 진짜 low-effort 발성, 숨섞임/속삭임은 서로 구분한다.
- 숨섞임은 백색잡음 추가로 대체했다고 주장하지 않는다. 진짜 속삭임/거친 발성은 후순위다.

이전 Conformer의 발화구간 피치 추가는0dB91.30→90.84%로 개선되지 않았다.
포먼트는 당시 dropout0.2 기준90.67→91.30%로 개선됐다. 다른 모델/선택 조건이므로 compact에서의 효과를 대신 증명하지는 않는다.

## 3. 보조 음향 경로: 이미 완료, 일괄 채택하지 않음

여기서 보조모델은 기존 set3 보조 입력 경로다. 외부 teacher나 새로운 보조손실이 아니다.
F1/F2/F3 포먼트, B1/B2/B3 대역폭6개와 관측 가능 여부6개를 작은 CNN으로32D 특징에 더한다.
추가4,720파라미터이며 실제 noisy 파형에서도 별도로 특징을 추출한다.

세 모델 모두1000epoch 완료했고 가중치·기록은 기존 acoustic-aux 릴리스에 있다.

| head | 기존→보조 0dB F1 | 기존→보조 명령어10종F1 | 기존→보조 잡음단독 오반응 |
|---|---:|---:|---:|
| Mean | 85.44→86.65% | 87.99→88.33% | 4.58→20.21% |
| Pooled | 86.77→85.00% | 86.49→84.94% | 11.88→4.58% |
| Self | 85.55→83.86% | 86.15→84.04% | 12.08→8.54% |

Mean의 원본F1은91.97→95.91%, 재시작→시작 혼동은98→45건이었다.
그러나 정지/전진/후진을 일괄 개선하지 못했고 잡음 오반응이 증가했다. Pooled/Self의 noisy 명령어F1은 하락했다.
따라서 Mean+보조를 후보로 보존하되 세 head에 일괄 적용하지 않는다.

다음 작업:

1. 새 기본 조건을 정하면 같은 모델/증강에서 보조ON/OFF를 비교한다. 기존3head 실험을 동일 조건으로 다시 돌릴 필요는 없다.
2. 스케일러는 해당 fold의 원본 학습 자료 유효 프레임으로만 적합한다.
3. 파형 증강·소음 혼합 후 각 view에서 보조 특징을 다시 계산한다. noisy 입력에 원본 특징을 대신 제공하지 않는다.
4. 시간 마스크를 쓸 때 보조 값/관측 채널도 같은 시간에 차단한다. 관측 가능 여부는 신뢰도 점수가 아니다.
5. 전체 처리시간에 Praat 추출 비용을 포함한다. 현재 추출기는24000샘플/151프레임 고정이므로 입력 길이 체계 변경 시 그 가정도 같이 수정해야 한다.

## 실행 순서와 판단 지표

소음 원본 확대와 화자 프로파일 샘플 검증을 독립적으로 준비하고, 한 축씩 고정 대조한다.
그다음 유효한 정책을 결합하고, 선택한 조건에서 보조ON/OFF를 확인한다.
전체11종F1, 명령어10종F1, 원본/소음 정답률, silence F1, 잡음단독 오반응,
재시작→시작 및 정지↔전진/후진 혼동을 함께 기록한다. 화자 일반화는 화자03 결과만으로 판정하지 않는다.
