# 연속 화자·환경 증강 설계 조사

상태: 조사/설계 제안. 새 증강 구현·다운로드·학습은 시작하지 않았다. 수치 예시는 우리 데이터에서 검증할 초기 후보이며 논문이 보장한 최적값이나 확정 설정이 아니다.

## 사용자 의도와 기존 설정의 차이

사용자 요청은 포먼트·피치·속도를 연속 범위로 관리하고, 파일마다 비교적 다른 화자 스타일을 주되 한 파일 안에서는 덜 변하게 하면서도 상수가 아닌 변화를 주는 것이다. 속도는 파일 간 분산도 작게 유지한다. 여기서는 '급격한 변화'를 파일마다 기본값 차이를 줄 수 있다는 뜻으로 해석하고 파일 내 파라미터 점프는 피한다. 실제 뜻이 다르면 구현 전에 이 해석을 조정한다.

기존 compact는 포먼트만 파일당 고정2변형,피치/속도OFF. 과거4anchor 피치코드는 내부 두 값의 차이가0.35반음 미만이면 강제로 벌렸고 양끝을0으로 고정했다. 새 목표에서는 최소 변화량을 강제하지 않고, 파일 전체의기본값과 작고완만한편차를 분리한다. 양끝도 기본값을 유지해야 가상 화자 스타일이 중간에만 나타나는 문제가 줄어든다.

## 1. 두 수준으로 제어

시간을t라 할 때 다음을 사용한다.

```
pitch_shift(t)       = file_pitch_offset + small_smooth_pitch(t)       # 반음
log(formant_ratio(t))= file_log_formant + small_smooth_formant(t)       # 로그비율
log(speed_rate(t))   = file_log_speed + smaller_smooth_speed(t)         # 양수 속도
```

파일기본값 분산과 파일내곡선 분산,곡선의최대기울기,전체상한/하한,적용확률을 각각 설정한다. 파일내분산은 파일간분산보다 작게 한다. 속도는 두 분산 모두 작게 한다. 곡선을 매프레임독립난수로 만들지 않는다.

### 재현 가능한 샘플러

- seed는(global_seed,train_fold,원본ID,epoch,view,component)로결정한다. 같은원본파생물은동일fold에둔다.
- 기본값은절단정규분포/중앙에무게를둔유계분포로뽑고 일부는무변형으로유지한다. 매번최대강도만사용하지않는다.
- 1.5초에2~4개정도의완만한제어점을둔유계B-spline/PCHIP/저역통과곡선을후보로한다. 실제유효발화길이에따라제어점수를줄인다. 보간후값뿐아니라최대기울기도검사하고위반곡선은재샘플한다.
- 기본값이범위끝에가까우면허용되는작은변화폭도줄인다. 제어점을범위내로샘플하고보간overshoot를검사한다. 단순clip으로긴평평한구간을만들지않는다.
- 기본값주위의곡선평균은대략0이되도록조정한다. 곡선양끝은기본값주변에서유지하고파형처리의경계는crossfade/위상연속성으로다룬다.
- 가상스타일분포를정답명령어와독립적으로샘플한다. 특정명령어에특정피치/음색을배정하지않는다. 프로파일묶음을여러명령어에공통적용하는실험도가능하다.
- 피치/포먼트간약한상관을주는공통latent변수는비교후보다. 두값을항상같은방향/고정비율로묶거나성별2종으로단정하지않는다. 작은훈련집단의상관을자연화자전체의분포로취급하지않는다.

### 초기에 검증할 범위 예시

| 요소 | 파일 전체 기본값 | 파일 안 작은 변화 | 설계 의도 |
|---|---|---|---|
| 피치 | 예: -2~+2반음 | 예: 기본값주위±0.2~0.4반음,느린곡선 | 화자간높이차이와작은억양차이분리 |
| 포먼트 | 우선기존0.909~1.1총범위유지 | 예: 기본비율주위약±1%,총범위내제한 | 기본음색은유지하고국소변화를조금추가 |
| 속도 | 예:0.97~1.03배 | 예:기본값주위±1%,총0.95~1.05내 | 데이터간/파일내변화를모두약하게 |

피치/포먼트범위를넓힐때는시간내흔들림을동시에키우지않는다. 예를들어'기본값분포만확대'와'파일내작은곡선만추가'를분리한다. 넓은기본값이진짜다른화자를모방한다는보장은없다. 같은원본의합성변형으로새화자의모든조음·억양·발음습관을생성할수는없다.

### 원래 발화 변화와 증강 곡선의 구분

작게제한할것은증강으로추가하는변화이지,원래피치/포먼트의언어적움직임을평평하게만드는것이아니다. 기본피치이동은원래F0곡선위에반음offset을더하는식으로정의하고,억양폭조절은별도정책으로분리한다. 무성구간에가짜F0를부여하지않는다. F1/F2/F3를서로독립적으로크게움직이면다른모음으로들릴수있어공통spectral-envelope warp부터검증한다.

## 2. 구현 가능성과 비용

기존Praat Change gender호출은파일전체의상수formant ratio용이다. 숫자배열을넘긴다고시간가변포먼트가되지않는다. 시간가변피치에는기존RubberBand pitch-scale갱신또는Praat pitch-tier경로를재사용할수있지만실제변형후F0와artifact를다시확인해야한다.

시간가변포먼트는source/filter분리후LPC/스펙트럼포락선만완만하게warping하고위상연속성을유지해재합성하는방법을구현후보로조사한다. 구현·검증은아직하지않았다. 프레임별결과를그냥이어붙이지않는다. 원시FFT전체주파수를늘리면피치도함께움직일수있으므로포먼트단독제어와구분한다.

시간가변속도는양수속도를적분한단조시간맵으로정의하되,파형단순보간만하면피치가변할수있다. 피치보존시간신축엔진의지원/품질을검증해야한다. 변형후무조건원길이로재신축하면평균속도변화가상쇄되므로발화보호구간과1.5초패딩/overflow skip정책을명시한다. 총발화가잘리는변형은채택하지않는다.

특징공간VTLP는주파수warp의선행근거가있지만현재원시파형에서추출하는보조set3와불일치할수있다. mel만변형하고원본포먼트를그대로보조입력에주는것은동일한화자변형실험이아니다. 보조ON에서는파형변형후양쪽입력을재추출하는설계가우선이다. 파형변형과특징공간VTLP를무조건중복적용하지않는다. [VTLP 원논문](https://www.cs.toronto.edu/~ndjaitly/jaitly-icml13.pdf)

## 5. 현재 두 view 분류+지도대조학습과 마스킹

현재는reference/noisy두view모두에CE를걸고,같은명령어표현을가깝게하는SupCon을추가한다. reference는추가잡음전일뿐완전clean이아니다. 초기에는화자변형프로파일을두view에공유해서소음/마스킹의효과를분리한다. 서로다른가상스타일을positive로묶는것은그다음별도실험이다.

SpecAugment는필터뱅크의시간/주파수구간을가리는방법이다. 원논문은긴ASR자료의결과이며짧은한국어명령어의핵심구간이보존된다는보장은없다. [원논문](https://arxiv.org/abs/1904.08779)

### 왜 모든 주요 특징을 가리면 안 되는가

예를들어'재시작'의구별구간이완전히사라져다른명령어처럼들리면,원래라벨CE도강제positive정렬도모호한입력에같은정답을요구한다. 다른view에정답단서가있다고masked view의정보손실이복구되는것은아니다. 어텐션최대구간을무조건가리는정책도현재단계에선보류한다. 현재attention weight는넓은CNN문맥의가중치이며음소중요도정답이아니다.

### 보수적인 비교 후보

- 최소한reference한view는마스킹하지않는다. 처음에는noisy view에만약한마스킹을적용해안정적인분류anchor를남긴다.
- 시간은예를들어10~20ms(10ms hop의1~2프레임)부터,횟수/총가림비율을제한한다. 이수치도구별음소보존을보장하지않으므로청취/사례감사가필요하다. STFT창은겹친다는점도고려한다.
- 주파수는예를들어64mel중1~2band부터시작하고한번에넓은연속대역/여러핵심대역을지우지않는다. 소프트감쇠와완전가림을분리비교한다.
- 원본길이대비비율뿐아니라유효발화길이대비비율도제한한다. padding만가려효과없는경우와발화만가려너무강한경우를구분한다. VAD는보조진단이지정답경계가아니다.
- 어려운혼동파일의검수된구별구간이있다면보호할수있다. 현재는음소정렬/사람청취완료가아니므로자동으로그구간을안다고가정하지않는다.
- 변형강도에따른CE/SupCon가중치비교를별도후보로둔다. 너무손상된view는약하게정렬하거나제외하는방법을검토하되,단순loss하향만으로잃어버린정답단서가생긴다고설명하지않는다. 모델confidence도라벨보존의증거는아니다.

### 보조 입력의 우회와 정렬

시간마스크는보조값/availability의같은구간도차단한다. 현재보조backbone은rawHz를저장된mean/std로정규화한뒤availability를곱하므로raw값을0으로만바꾸지않고availability도0으로한다. mel의무음floor와표준화0(평균값)은같지않아마스크fill정의를고정한다.

주파수마스크는보조포먼트경로가같은단서를볼수있다. 'mel만가림'과'보조경로도dropout'은다른실험으로기록한다. 주파수마스크구간만으로어느포먼트를완벽히삭제할수있다고가정하지않는다. 필요하면마스킹첫실험은보조OFF고정으로단순화하되대조군도동일하게OFF로한다.

## 6. 제안 파이프라인과 확인 절차

```
원본 → 가상스타일기본값+완만한곡선 → 피치/포먼트/시간변형
     → 선택적RIR/마이크응답 → reference
                               └→ 추가소음 → noisy
각view에서mel+보조재추출 → 선택적으로noisy view만약한mask → CE+SupCon
```

이는효과를분리하는첫설계다. 두view의독립환경변형/독립화자변형은후속조건이며한번에모두켜지않는다. 실제마이크변형은소음까지함께작용할수있으므로추후전체믹스에EQ를거는조건과음성에만거는조건을구분한다. 원본에이미있는소음은화자변형시함께변할수있고,간단VAD/crossfade로겹친배경을분리할수없다.

먼저학습없이명령어/화자별변형예시를생성해사람청취와측정으로검증한다. F0/포먼트의요청값대비실제변화,곡선의최대기울기,발화보존/끝음절잘림,peak/RMS/길이/지연/finite,경계artifact를확인한다. 측정기의성공이음소보존증명은아니다. 샘플·seed・곡선・skip사유를보존한다.

그뒤A=기존포먼트상수기준,B=새연속프로파일,C=B+약한EQ/에너지,D=B+마스킹을분리비교하고환경원본확장실험도별도축으로둔다. 초기비교는같은모델/손실/LR/batch/seed/학습예산을유지한다. 최고점뿐아니라명령어10종F1,원본/소음accuracy,silence F1,잡음단독오반응,검출기미검출,정지↔전진/후진/재시작오답과각변형강도별곡선을본다. 무변형검증과실제새화자/새환경평가를유지한다.

## 결정이 아직 필요한 항목

파일간피치/포먼트범위를얼마나넓힐지,파일내상한/기울기,원래억양폭을별도로바꿀지,보조ON/OFF,검출기조건,화자곡선/환경확장의실험순서. 본문범위는초안이며전체1000epoch학습을새로시작한상태가아니다.
