# 시연 및 응용 사례: 음성 명령 기반 게임

> 편집용 1차 초안. 절·표·그림 번호는 전체 보고서 편집 시 부여한다. 수치는 기존 실행 결과이며 직접 편집하지 않는다.

## 방법

기존 게임의 core.mjs simulate/evaluate를 직접 불러 자동 실행했다. 음향 10조건에서 각각 10,000게임을 반복했다. 1게임은 최대 20라운드이며 실패 3회에 도달하면 즉시 종료한다. 기본 제한시간은 3200ms, 처리 지연 배율은 ×100, seed는 42이다. 반응시간은 중앙값 450ms, 로그 표준편차 σ=0.35인 로그정규 가정 분포로 표집하며 자동 조종은 항상 요구 버튼을 선택한다.

명령은 10종 균등 표집, 해당 명령의 녹음 3개 중 균등 복원 표집한다. 판정은 올바른 버튼 ∧ 올바른 인식 ∧ 반응시간+녹음 길이+실측 처리시간×배율 ≤ 제한시간이다. 모든 조건에서 같은 seed를 사용하므로 조건 간 비교는 공통 난수에 의한 짝지어진 비교다.

## 보고서에 붙일 설명

본 시뮬레이션은 개발 검증 화자 spk03의 30개 원본 녹음으로 만든 300개 고정 음성 조건의 실제 사전 추론 결과를 재표집하였다. 각 음향 조건의 bank 자체 인식 일치율은 bank-conditions.csv(n=30), 명령별 결과는 bank-commands.csv(n=3)에 별도로 제공한다. 전송 인식 일치율은 게임에서 표집된 결과의 일치율이며 bank 전체 비율과 구분한다.

생존율의 95% 구간은 고정 bank와 가정한 반응시간 분포 아래 반복 시뮬레이션의 Wilson 구간이다. 녹음·화자·모델의 일반화 불확실성을 나타내지 않는다. 반복 수를 늘려도 새로운 음성 평가가 늘어나는 것은 아니다. 반응시간은 사람에게서 실측·보정하지 않았고, 조작 실수는 가정하지 않았다. 따라서 사람의 실제 플레이 성과로 해석할 수 없다.

검출기는 미연결이며, 브라우저 실시간 추론·새 독립 test 성능·검출기 포함 전체 방식의 성능이 아니다. SNR은 원본 전체 1.5초 파형 전력 기준이다. 처리 지연 ×100는 시연 배율이며 하드웨어 실측 시간을 그대로 의미하지 않는다. unscaled_compute는 같은 bank의 실측 compute_ms에 ×1만 적용한 비교로, 실제 시스템 종단 지연 측정이 아니다.

## 그림

- survival.png / survival.pdf: 음향 조건별 무사귀환율과 95% Monte Carlo 구간. analytic_survival은 같은 가정의 수식 검산값이다.
- deadline-sweep.png / .pdf: 제한시간에 따른 생존율 민감도.
- failure-flags.png / .pdf: 진행한 라운드의 인식 오류·시간 초과·교집합 비율. 두 오류 막대는 중복될 수 있다.
- compute-scale.png / .pdf: 기본 배율과 ×1 비교.

그림의 축은 글꼴 호환성을 위해 영어로 표기했다. PNG는 220dpi, PDF는 벡터 출력이다.

## 재현 및 해석 메모 (집필 시 부록 이동 가능)

summary.json에 설정·코드/bank SHA-256·모델·소음 출처를 저장했다. games.csv는 모든 시나리오의 게임별 결과다. 선택한 --round-logs 옵션은 기본 시나리오의 라운드 원시 행도 기록한다. 독립·동일분포 라운드 가정 아래 이항 생존확률을 별도로 계산하여 시뮬레이션과 대조했다.

약간의 게임식 표현: 이 표의 ‘폭발’은 로봇의 퇴근 실패를 뜻한다. 로봇 보험료는 계산하지 않았다.


## 전체 보고서 연결 문단 후보

본 연구의 명령어 분류 결과가 연속 작업의 성공에 미치는 영향을 직관적으로 설명하기 위해 상황 대응 게임을 구성하였다. 단일 명령의 인식 일치 여부뿐 아니라 제한시간과 연속 라운드의 누적 실패를 함께 반영하여, 분류 결과를 응용 수준의 성공 지표로 변환하였다. 이하 결과는 고정된 개발 검증 음성에 대한 게임 시뮬레이션이며, 본 실험의 독립 평가를 대체하지 않는다.

## 논의 문단 후보

기본 조건에서 식당 소음0dB의 인식 일치율은 전송 기준66.55%였으나, 20라운드 중 누적 실패가3회 미만이어야 하는 게임의 무사귀환율은1.51%였다. 이는 단일 명령의 일치율과 연속 작업의 성공률이 서로 다른 지표임을 보여준다. 다만 자동 조종의 버튼 선택은 항상 정답이고 반응시간은 가정 분포이므로, 이 차이를 실제 사용자의 조작 능력이나 실제 현장 성공률로 해석해서는 안 된다. 또한 고정 bank의 작은 표본과 시연용 지연 배율의 영향은 후속 평가에서 별도로 검토할 필요가 있다.
