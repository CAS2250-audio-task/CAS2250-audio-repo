게임 시뮬레이션 결과를 전체 연구 보고서의 ‘시연 및 응용 사례’ 절로 미리 작성해줘. 이 채팅은 보고서 집필용으로 사용한다.

팀 저장소는 https://github.com/CAS2250-audio-task/CAS2250-audio-repo 이고 자료 브랜치는 `docs/command-rescue-report-20261116`이다. 저장소 안의 `reports/command-rescue-game/`를 작업 기준 폴더로 삼아 아래 상대 경로를 읽어라. 원격 서버의 `/root/` 경로에 접근할 필요는 없다. 기존 공유 보고서에 이 자료를 합치고, 그 보고서의 원래 편집 위치를 우선 사용해라.

먼저 `report-workspace/START_HERE_KO.md`, `report-workspace/DRAFT_KO.md`, `report-workspace/WORK_NOTES_KO.md`를 읽어라. 근거는 `reports/game-statistics-20261116/summary.json`, `summary.csv`, `REPORT_KO.md`, 그림 PNG/PDF, `VERIFICATION.json`, `ARTIFACTS.json`이다. 원시 게임 집계는 `games.csv.gz`다. 통계 코드는 `analysis/run-stats.mjs`, 판정의 원본은 `dist/core.mjs`다.

수치·조건·분모를 확인한 뒤 `report-workspace/DRAFT_KO.md`를 실제로 편집하여 다음 내용을 정리해라.

- 짧은 도입, 재현 가능한 실험 방법, 기본 조건 결과표, 제한시간/처리 지연 민감도 해석, 그림 설명, 해석 한계.
- 전체 보고서의 절 번호·기존 결과·서식은 현재 제공되지 않았다. 임의로 만들지 말고 연결할 부분을 `WORK_NOTES_KO.md`에 남겨라. 작성 가능한 본문은 먼저 완성해라.
- 기본 10조건 각1만 게임=10만 게임. 제한시간4개 추가 및 처리배율×1 비교까지 합쳐 총60만 게임이다. 설정이 다른 게임을 하나의 성능으로 섞지 마라.
- spk03 개발 검증 화자 원본30개에서 만든 고정300조건의 실제 사전 추론 결과를 재표집했다. 검출기 미연결, 사람 반응은 가정 로그정규(중앙값450ms/σ0.35), 자동은 항상 올바른 버튼을 누른다.
- 무사귀환은 최대20라운드를 실패3회 미만으로 마치는 것이다. 기본 제한3200ms/실측 처리 지연×100/seed42. 인식 일치율 분모는 실제 전송, 실패 플래그는 중복될 수 있다. 95% 구간은 고정 bank·가정 분포에 조건부인 Monte Carlo 생존율 Wilson 구간이다.
- 새 독립 test·실시간 브라우저 추론·실제 사람/친구의 플레이 실험·검출기 포함 최종 방식의 성능으로 표현하지 마라. SNR은 전체1.5초 파형 전력 기준이다.
- 어조는 보고서체를 유지하고 ‘로봇 무사귀환율’ 정도만 살짝 장난스럽게 써도 된다. 통계는 바꾸지 마라. 0/1만 귀환을 ‘귀환 확률이 절대0’이라고 단정하지 마라.

새 학습, 원본 데이터 재준비, spk01/test 접근이나 반복 시뮬레이션 재실행은 집필에 필요하지 않다. 먼저 기존 근거로 초안을 다듬고 수정 내역·남은 확인 사항을 `WORK_NOTES_KO.md`에 적어라. 아직 확정되지 않은 본 실험 결과와 게임 결과를 혼합하지 마라.
