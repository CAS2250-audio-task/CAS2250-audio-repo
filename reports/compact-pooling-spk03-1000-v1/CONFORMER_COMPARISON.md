# 기존 Conformer와의 비교 및 silence 학습 확인

화자03 홀드아웃 결과를 비교한다. 기존 Conformer는 채택된 `formant_B` 조건이며 DFN은 사용하지 않는다. 명령 혼합 평가는 기존 소음8종·0dB·3draw의 소음별11클래스 macroF1 평균이다. 기존 모델 수치는 저장된 실험 보고서 기록이며 이번 서버에서 Conformer를 다시 학습한 값이 아니다.

| 모델 | 파라미터 | 원본 F1 | 0dB F1 | 잡음 단독 오반응률: 기존160crop |
|---|---:|---:|---:|---:|
| 기존 Conformer | 32,122,699 | 100.00% | 93.12% | 0.625% (1/160) |
| 소형 CNN + 평균 풀링 | 77,835 | 92.06% | 79.65% | 19.375% (31/160) |
| 소형 CNN + 풀드 어텐션 | 78,859 | 94.13% | 78.76% | 23.750% (38/160) |
| 소형 CNN + 셀프 어텐션 | 86,315 | 94.10% | 82.89% | 21.250% (34/160) |

잡음 단독 수치는 새 모델을 기존 코드의 `crop_noise(recording, "noise-only", noise_id, index0..19)`로 다시 평가한 값이다. 기존 Conformer와 crop 정의 및160개 표본 수를 맞췄다. 새 실험의 기본480crop 평가와는 표본이 다르므로, 이 표의21.25%와 기본 보고서의20.42%는 다른 평가다. 원본 소음은 같은 공개 원본에서 복원했으며, 준비 파형 재생성 라이브러리 차이까지 바이트 단위로 같다고 주장하지 않는다.

소형 셀프 어텐션은 Conformer보다 파라미터가 약372배 적고99.73% 감소했지만0dB F1은10.23%p 낮다. 현재 결과로는 소음 일반화 성능을 유지한 대체 모델이라고 할 수 없다. 추론 지연을 같은 환경에서 측정한 결과는 아니므로 파라미터 감소를 그대로 속도 개선 배수로 해석하지 않는다.

## 학습 조건의 차이

| 조건 | 기존 Conformer | 이번 소형 CNN |
|---|---|---|
| 초기화 | 한국어 ASR 사전학습 가중치 | 무작위 초기화 |
| 입력 특징 | SpeechBrain80차원 Fbank·ASR 정규화 | 64차원 log-mel·학습 화자별 통계 |
| batch | 16 | 32 |
| 샘플링 | inverse-class WeightedRandomSampler, 복원추출 | 매 epoch609개를 섞어 한 번씩 순회 |
| silence 비율 | 기대값1/11 ≈9.09% | 9/609 ≈1.48% |
| 학습 예산 | 100epoch | 100epoch + LR 재시작 후900epoch |

소음 p0.5, SNR[-5,20]dB와 약한 포먼트 p0.5라는 정책은 같지만 위 조건까지 같은 비교는 아니다. 특히 **기존과 클래스 샘플링을 맞추지 못했다**. silence의 기대 학습 노출이 약6.15배 달라 잡음 거절 성능 차이를 모델 구조나 사전학습 하나의 효과로 분리할 수 없다. 소형3모델끼리는 동일 샘플링과 증강 입력으로 비교했다.

## 잡음 단독을 silence로 학습했는가

둘 다 **무발화 녹음(silence)에 소음을 섞어도 silence 라벨을 유지**한다. 따라서 잡음만 있는 상황을 silence로 분류하는 학습은 포함돼 있다. 다만 별도로 `영 파형 + 소음`만 대량 생성한 전용 학습 세트를 넣은 것은 아니다. 그런 완전한 잡음 단독 파형은 현재 평가에서 사용한다.

화자03 분할은 학습 명령600개 + silence9개다. 원래 silence 파형도 비영 파워의 녹음이며 완전한0파형은 아니다. 이번 소형 모델은 silence9개를 매 epoch 한 번씩 보고 그중 평균4.5개에 추가 소음을 섞는다. 기존 Conformer는 클래스 균등 샘플링으로 silence를 기대값 약55.4회/epoch 보고, 그중 약27.7회에 소음을 섞는다. 이 횟수는 기댓값이며 실제 값은 draw마다 달라진다.

현재 학습에는 명령이 아닌 타인 말소리를 별도의 unknown/거절 클래스로 명시적으로 추가하지 않았다. 잡음을 명령에 섞는 증강과, 명령이 전혀 없는 음성을 거절하도록 학습하는 것은 구분해야 한다.
