# 보조 음향 특징 실험 결과

학습은 고정 1.5초 WAV 그대로, 증강 OFF. **원본 validation macro F1이 주 평가·체크포인트 선택 기준**이다.

관찰한 효과와 한계: [결과 해석](interpretation.md).

0~7세트 screening 8회, 추가 시드 6회, 결합 방식/용량 대조 2회로 총 16회 학습했다. 이번 설정에서는 보조 입력의 성능 개선을 확인하지 못해 **기준 모델(세트 0)을 유지**한다. 이는 고정된 10-epoch 학습·한 명의 validation 화자에서 얻은 결론이다.

## 해석과 한계

- train 609 / val 203 / test 203, 화자 분리 유지. val은 한 화자이므로 새 화자 전체의 성능을 보장하지 않는다.
- 203개에서 한 파일 차이는 정확도 약 0.49%p다. 반복 seed 평균/표준편차는 `seed_summary.csv`를 참고한다.
- 소음 평가의 복사본들은 독립적인 새 화자/원본 예제가 아니다. 조건별 강건성 분석용이다.
- 측정 불가는 오측정과 다르다. 포먼트/피치가 수치로 나와도 틀릴 수 있다. availability는 정답 품질이 아니다.
- RMS <= 1e-8(-160 dBFS) 검사는 PCM16 원본에서는 사실상 디지털 0 분석 창 검사다. 약한 발화의 음량 문턱이나 포먼트의 물리적 부재 판정이 아니다.
- 소음 SNR은 기존 녹음 full-clip 파워 대 추가 잡음이며, 원래 무잡음 음성의 SNR이 아니다.
- silence/noise-only의 명목 소음 레벨은 train keyword RMS 중앙값 기준이다. 잡음 단독은 144개다.
- 주 실험의 원래 ResNet 512→11 head와 학습 설정을 유지했다. 보조 경로 때문에 늘어난 용량은 capacity control로 추가 확인한다.
