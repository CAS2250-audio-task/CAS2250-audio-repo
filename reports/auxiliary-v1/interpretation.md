# 결과 해석

이번 비교에서는 보조 음향 특징을 추가한 모델이 기준 모델보다 일관되게 좋아지지 않았다.
기준 모델을 유지한다. 이것은 **현재 구조·학습 설정에서 개선을 확인하지 못했다**는 뜻이며,
포먼트나 피치 정보 자체가 쓸모없다는 결론은 아니다.

## 원본 validation

0~7세트를 seed42로 실행한 뒤, 원본 validation macro F1 상위 보조 세트 3·4와 기준을
seed43/44로 확인했다. 총 16회 학습 중 14회는 이 비교이고, 2회는 결합 방식과 용량 대조다.
모든 실행은 10 epochs이며 최적 epoch는 원본 validation macro F1으로 선택했다.

| 구성 | 3시드 평균 F1 | 시드 표준편차 | 기준 대비 평균 차이 |
| --- | --- | --- | --- |
| 기준 | 89.26% | 3.65%p | — |
| F1~F3 + B1~B3 | 86.60% | 5.14%p | -2.66%p |
| F1~F3 + 변화량 | 89.09% | 3.79%p | -0.17%p |

포먼트+변화량의 시드별 기준 대비 차이는 -1.44 / +1.45 / -0.51%p다.
평균 차이가 작고 방향도 일정하지 않다. 단 세 시드와 한 명의 validation 화자로
통계적 동등성이나 명확한 우열을 주장하지 않는다. 사전에 정한 평균 점수 기준으로 기준 모델을 유지했다.

seed42에서는 포먼트+대역폭이 기준의 오답 9개를 고쳤지만 정답 9개를 새로 틀려 정확도가 같았다.
RMS 세트는 4개를 고치고 17개를 새로 틀렸으며, 전체 특징 세트는 7개를 고치고 14개를 새로 틀렸다.
추가 입력 수가 늘어난다고 이 설정의 결과가 좋아지지는 않았다.
이것만으로 RMS가 모든 구조·환경에서 무용하다고 판정할 수는 없다.

`validation_case_review.md`는 오류 사례 20개의 예측·측정 가능 비율을 정리한 점검 자료다.
청취 기반의 원인 판정은 포함하지 않았다. 예를 들어 `오른쪽→왼쪽`, `재시작→시작` 같은 혼동은
관측했지만, 실제 발음·구간·잡음 중 무엇이 원인인지는 이 표만으로 확정할 수 없다.

## 소음 평가와 측정 불가 표시

학습 증강은 끈 상태다. 아래 소음은 평가 복사본에만 추가했고, 매 조건에서 특징을 다시 추출했다.
seed42의 F0 세트는 noisy validation 평균 F1이 44.39%로 기준 42.90%보다 조금 높았다.
그러나 잡음 단독의 단어 오인율은 36.81%로 기준 9.03%보다 높았다.
이 한 번의 결과를 전반적인 소음 강건성 향상으로 해석하지 않는다. 해당 세트의 추가 시드도
주 평가 기준의 상위 두 후보에 들지 않아 실행하지 않았다.

기준의 noisy validation F1은 추가 잡음 20 / 10 / 0 dB에서 각각 평균 65.03 / 42.91 / 20.76%다.
이 SNR은 기존 녹음 전체 파워 대 추가 잡음 파워이며, 깨끗한 발화만의 SNR이 아니다.
여러 조건은 같은 발화와 잡음 구간을 재사용하므로 독립적인 신규 데이터셋으로 세지 않는다.

현재 마스크는 측정값 사용 가능 여부다. 포먼트의 물리적 존재나 추정 정확도의 정답이 아니다.
분석 창 RMS <= 1e-8 검사는 현재 PCM16 원본에서 사실상 전체 0 창을 가려내는 최소 검사다.
소리를 작게 만들었다고 포먼트가 사라지는 것은 아니며, 잡음이 있는 창도 이 검사를 통과한다.
음량 문턱을 높이거나 신뢰도 기반으로 추가 제외하는 방법은 별도 비교가 필요하다.
이번 결과를 본 뒤 추출 임계값을 바꾸지는 않았다.

## 결합 방식과 비용

세트 3의 seed42 원본 val F1은 시간 정렬 중간 결합 92.24%, global late fusion 91.44%였다.
파라미터 수를 맞춘 spectral-only 대조군은 89.57%였다. 모두 한 시드의 보조 비교이므로
구조의 일반적인 우열이나 추가 정보 자체의 독립적인 효과를 확정하지 않는다.

보조 모델은 파라미터가 기준보다 약 0.36~0.40% 늘었다. 캐시를 사용한 학습·검증 시간은
기준 약 4~5초, 보조 약 13~14초였으며, 여기에 특징 추출 시간은 포함되지 않는다.
뒤쪽 512차원 표현과 Linear(11) 형태는 유지하므로 다음 head/멀티태스크 실험에 재사용할 수 있다.

## 최종 test와 보존 상태

반복 validation 결과로 세트 0 선택을 먼저 고정한 후, 사전 지정한 seed42 모델만 평가했다.
원본 test는 **148/203 정답, 정확도 72.91%, macro F1 74.88%**다.
기준 모델 자체가 선택되어 보조 모델의 test는 열지 않았다. Validation과의 차이는
새 화자 일반화의 한계를 점검할 근거지만, 화자만이 원인이라고 분리해 증명한 것은 아니다.
Noisy test 평균 F1은 36.63%, 잡음 단독의 단어 오인율은 13.89%였다.

Test 결과를 이용한 재튜닝은 하지 않았다. 이후 모델 선택도 validation에서 진행하고,
이번에 공개된 test 점수를 설정 선택의 근거로 사용하지 않는다.

기존 src/configs/notebooks, 전처리 코드, 데이터 파일은 기준 커밋과 동일하다.
원본 WAV 1,015개·M4A 1,015개·ZIP을 보존했고, 고정 1.5초 WAV 1,015개의 해시도 확인했다.
캐시 28개와 가중치 16개의 해시, 실행 소스·지표 검증은 `execution_audit.json`에 기록했다.
전체 테스트는 39개 통과했다. 과거 환경의 점수는 이번 비교의 기준으로 사용하지 않았다.
