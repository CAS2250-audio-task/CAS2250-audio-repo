# 공통 CNN · 집계 방식 비교 · 증강 적용

학습 목적: paired_supcon

검출기/발화확률/사전학습 없이 전체 1.5초를 입력한다. 검증 화자: ['spk03']. 각 분할은 나머지 개발화자3명만 학습한다.
소음 p=1.0, SNR [-5,20]dB + 약한 포먼트 p=0.5. 모델은 같은 CNN·분류기 초기값과 같은 증강 입력을 사용하고 독립 학습한다.

| 모델 | 파라미터 | 화자 | 선택 epoch | 원본 F1 | 0dB F1 (3draw) | 마지막 epoch 0dB F1 | 잡음 단독 오반응률 |
|---|---:|---|---:|---:|---:|---:|---:|
| cnn_mean | 78,635 | spk03 | 590 | 93.89% | 84.93% | 80.19% | 15.21% |
| cnn_pooled_query | 79,659 | spk03 | 408 | 87.05% | 76.23% | 70.78% | 24.17% |
| cnn_self_cls | 87,115 | spk03 | 573 | 94.49% | 83.49% | 80.55% | 8.96% |

한 seed·개발 1분할의 선별 결과다. 0dB draw0로 체크포인트를 선택했고, 최종 3draw에도 draw0가 포함된다. 독립 test 성능이나 검출기 효과를 의미하지 않는다.
기존 4분할 Conformer 결과와는 모델·학습 초기화·전처리·검증 분할이 달라 직접적인 개선 수치로 해석할 수 없다.
