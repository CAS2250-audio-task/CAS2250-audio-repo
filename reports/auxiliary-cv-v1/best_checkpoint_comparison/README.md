# 보조 제외/포함: 각자의 최고 성능 체크포인트 비교

같은 공통 학습 조건·seed44에서 각 세트가 원래 검증 Macro F1로 선택한 최고 epoch끼리 비교했다. epoch3 또는10으로 맞춘 직전 분석과 구분한다. 새 학습이나 조건 재선택은 하지 않았다.

| 화자 | 세트0 epoch / F1 | 세트3 epoch / F1 | 차이 | 정답 수 세트0→3 | 세트3만 정답 / 세트0만 정답 |
| --- | ---: | ---: | ---: | ---: | ---: |
| [spk01](spk01.md) | 4 / 58.46% | 3 / 71.86% | +13.40%p | 115→140 | 40 / 15 |
| [spk02](spk02.md) | 4 / 62.82% | 3 / 70.14% | +7.32%p | 126→136 | 36 / 26 |
| [spk03](spk03.md) | 8 / 87.02% | 7 / 87.59% | +0.57%p | 175→176 | 13 / 12 |
| [spk04](spk04.md) | 9 / 84.73% | 9 / 87.42% | +2.70%p | 173→180 | 12 / 5 |

spk01은 각각 spk02 검증에서 선택한 epoch4/3 모델을 그대로 평가했다. spk01의 결과로 epoch를 고르거나 두 모델 중 하나를 선택하지 않았다. spk02/03/04는 각자 미학습 화자로 둔 고유 CV fold이며 이 네 행을 하나의 CV 평균으로 합치지 않는다.

세트3은 이 비교의 네 행에서 F1이 높다. 화자2에서는 +7.32%p, 정답10개 증가지만 세트0만 맞히는 파일26개도 남는다. 화자3의 F1 차이는 +0.57%p로 작고 loss는 오히려 세트0이 낮다.

## 자료와 검증

- 각 화자 문서에 세트3만 정답·세트0만 정답·둘 다 오답인 전체 파일과 양쪽 예측, WAV 링크가 있다.
- 전체 CSV에는203개씩 정답·양쪽 예측·정답확률·NLL·선택 epoch·원본 파일명·패딩을 넣었다.
- [앞서 악화했던 화자2의43개를 최고점끼리 대조](spk02_previous_43_at_best.csv).
- 선택 epoch가 원래 history의 최초 최고 F1 시점인지 확인했다. spk02/03/04는 각 선택 epoch의 예측이 원래 저장된 best checkpoint 예측과 정확히 일치했다.
- 두 세트×4화자=1,624개 예측에서 정확도·Macro F1·NLL을 재계산했다. 원래 checkpoint·예측 파일의 해시를 analysis_audit.json에 기록했다.
- 한 시드의 개발 검증 최고점이다. 독립 최종 test나 청취 기반 원인 판정으로 해석하지 않는다.
