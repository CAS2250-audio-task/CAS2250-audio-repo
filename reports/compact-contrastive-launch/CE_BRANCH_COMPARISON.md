# 분류 CE만 사용한 다른 브랜치와 비교

**화자02의100epoch 비교에서는 소음 대조+Pooled, 화자 대조+Self가 개선됐다. 화자03의대조학습 점수도높지만1000epoch 대100epoch이므로로스개선량으로해석하지않는다.**

CE 출처: compact-pooling-v1 commit `f7514137e0f83bd37b5d9a71889f6bd6c5d2731b`. 해당 원격에서 조회한 완료 결과는100epoch CE다. 최신commit에는화자03의100→1000epoch 연장 코드·프로토콜이있지만 summary/완료결과는없어비교에쓰지않았다.

## 최고checkpoint의0dB macro F1

모든점수는각모델의고정0dB draw0 최고에서선택된checkpoint를같은8소음×3crop으로평가한점수다. 원본F1 최고와섞지않았다.

## 같은 조건과 다른 조건

- **같음:** 개발812개원본 WAV의경로·SHA256, 학습/평가소음원본manifest, 64-bin frontend 설정, label순서, models.py소스해시. 모델구조/파라미터수, seed42, 화자별609train/203val, 약한포먼트정책, 최고checkpoint선택·최종평가방식도맞췄다.
- **입력·학습량이 다름:** CE는각원본에추가소음p0.5를적용한1뷰로609draw/epoch. 대조학습은동일포먼트변형원본+소음p1.0의2뷰, 총1218뷰/epoch이고두뷰에CE를적용한다. 따라서같은100epoch라도입력노출량과배치구성이같지않다.
- **학습예산이 다름:** CE는두화자모두100epoch/cosine100. 이서버의화자03은무작위초기화에서1000epoch/cosine1000, 화자02만100epoch다. 원격의새1000연장은epoch100 LAST와AdamW에서이어가는별도스케줄이다.
- **실행환경이 다름:** CE torch2.3.1/CUDA12.1, 대조학습 torch2.6/CUDA12.4. 두서버모두RTX3090이지만비트동일학습을주장하지않는다.

따라서이표는**완성된시스템의관측점수비교**다. 대조로스하나의인과효과를분리한결과는아니다. 같은환경·2뷰입력·SNR·스케줄을사용한paired-CE 대조군이있어야그효과를더정확히확인할수있다.
