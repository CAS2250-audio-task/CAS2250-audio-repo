# 모델 구조와 오답의 연결: 실제 attention 교차 진단

**단순한 ‘짧은 음절을 평균 내서 잃음’ 또는 ‘소음이 쿼리를 오염시킴’만으로 모든 오류를 설명할 수 없었다.** 구조상 가능한 실패 경로를 구분하고, frozen checkpoint에서 원본·소음 입력의 attention 가중치를 교체해 일부 경로를 직접 점검했다.

검증 대상은 화자03의 **소음+화자 대조**에서 선택한 각 모델이다. 원본203개, 같은 원본에8소음×3crop을 더한4,872조건을 사용했다. 추가 학습은 없고 spk01 음원은 읽지 않았다. Pooled/Self의 기존 예측10,150개를 재추론해 저장 예측과 전부 일치함을 확인했다.

## 1. 실제 구현은 무엇인가

모든 모델은 같은 구조의 CNN으로 시간별32차원 특징 h_t를 만든다. 초기값은 맞췄지만 이후 독립 학습해 CNN의 최종 가중치는 다르다. 공통 CNN의 이론적 시간 수용영역은109프레임, 약1.105초다. 따라서 h_t는 해당10ms만의 정보가 아니며, attention 최고점의 시간을 곧바로 특정 음절의 위치로 해석할 수 없다.

### 평균 풀링

`z = mean(h_t) → Linear(32,11)`

집계부가 모든 시점의 특징을 같은 비중으로 더한다. CNN이 이미 단어를 구별할 특징을 만들어야 하고, 집계부가 특정 구간을 추가로 강조하거나 소음 구간을 따로 제외하지는 않는다.

### Pooled query

`q = W·mean(h_t), k_t = v_t = W·h_t → softmax(q·k_t/√32) → 가중합`

입력 전체 평균을 기준으로 어떤 시간 특징을 많이 가져올지 정한다. q·k·v에 같은 선형변환을 사용한다. 이 자체가 음성과 소음을 분리하는 규칙은 아니다. 전체 입력 특징이 소음에 변하면 쿼리뿐 아니라 key/value도 함께 달라진다.

### Self-attention + CLS

`[학습 CLS, h_1,…,h_T] + 위치표현 → Transformer1블록(d32,head2,FFN64) → CLS출력`

현재 모델은 **정확히1블록**이다. 첫 블록에 들어가는 CLS벡터와 그 위치표현은 모든 음성에 공통이므로 **최종 요약을 읽는 CLS query는 입력마다 동일하다.** 소음에 따라 바뀌는 것은 CNN특징에서 만든 key/value와 그 결과인 attention이다. 두 번째 블록이 있다면 이전에 음성을 반영한 CLS로 query를 만들 수 있지만 현재 구현은 그렇지 않다.

다른 시점의 self-attention 출력도 계산하지만, 한 블록 뒤에서 CLS만 사용한다. 따라서 최종 출력을 이해할 때는 위치정보·두 헤드·별도Q/K/V·FFN이 있는 학습형attention pooling으로 보는 것도 도움이 된다. 긴 Transformer가 여러 단계로 음성 문맥을 추론하는 구조와 동일시하지 않는다.

## 2. 구조와 관찰된 오류를 연결하면

### 평균 풀링: 집계 가중치가 흔들리는 경로는 없지만 특징 손상은 남음

소음 오답679건 중516건(76.0%)은 원본에서는 맞았던 입력이다. 가중치는 항상 동일하므로 이 변화를 ‘attention이 잘못된 구간을 선택해서’라고 설명할 수 없다. 입력/전처리/CNN특징이 바뀌고, 그 평균이 분류 경계를 넘어간 경우다.

재시작→시작127건, 역방향3건이라는 비대칭은 재시작을 구별하는 단서를 충분히 유지하지 못하는 패턴과 맞는다. 전체 특징을 평균 내는 구조에서는 짧거나 국소적인 단서가 CNN에서 충분히 강조되지 않으면 최종 평균에 약하게 반영될 수 있다. **그러나 실제 재 음절이 지워졌다는 결론은 아직 가설**이다. CNN이 넓은 문맥을 사용하므로 단순한 원시프레임 평균과 다르다.

이 모델은 집계부의 선택 규칙을 추가로 학습하지 않아 그 경로의 변동이 없다. 현재 화자03에서 가장 안정적인 관측과 일치하지만, 이것만으로 작은 데이터에서 평균 풀링이 항상 우월하다고 일반화하지 않는다.

### Pooled query: 선택적 강조는 가능하지만 q만의 문제가 아님

재시작→시작은 CE131→소음대조64→소음+화자43건으로 줄었다. 평균 모델보다 재시작 구별이 좋은 것은 일부 특징을 선택적으로 강조할 수 있는 구조와 양립한다. 다만 최종CNN도 다르므로 이 개선을 가중 풀링 단독의 효과로 단정하지 않는다.

원본에서 이미 틀리는 전진132/후진188 같은 파일이 있다. 이런 경우에는 더 좋은 소음 구간 선택만으로 해결하기 어렵다. q를 원본으로 바꿔도 전진132의24오답은 그대로였다.

### Self+CLS: query오염 설명은 맞지 않고 선택/특징/분류 경계를 봐야 함

이 모델의 CLS query는 실제 원본·소음 모든 쌍에서 정확히 동일했다. 따라서 오른쪽→왼쪽103건 같은 오류를 ‘소음이 CLS query를 바꿔서’라고 설명하는 것은 현재 구현에서 틀리다.

별도Q/K/V, 두헤드, 위치표현과FFN은 특정 음향 패턴·위치에 다른 반응을 학습할 수 있게 한다. 소음+화자 대조를 추가했을 때 재시작 오류166→66은 줄었지만 오른쪽88→146, 정지88→126으로 늘었다. 같은 명령어의 표현을 모으는 목적이 모든 명령어 구별의 개선으로 이어지지는 않았다는 관측이다. 특정 음소 특징을 실제로 제거했는지 또는 군집이 겹쳤는지는 아직 직접 측정하지 않았다.

오른쪽076은 원본부터 왼쪽이고24소음조건에서도 모두왼쪽이다. 이 예는 소음에 의한 attention 변화만으로는 설명되지 않는 이미 학습된 결정의 오류다.

## 3. 직접 진단: 원본과 소음의 가중치를 바꿔 보았다

같은 발화의 원본과 소음 입력을 고정모델에 통과시켜 각각CNN특징과attention을 얻었다. 이후 **소음 입력의value특징은 유지하면서, attention 가중치만 원본 입력에서 가져와** 분류했다. Pooled에서는 추가로 **query만 원본에서 가져오고 key/value는 소음 입력 것을 유지**했다.

이때 원본은 추가 합성소음 전 녹음이며 완전 무잡음이라는 뜻이 아니다. 실제 배포에서는 원본을 받을 수 없으므로 **원인 경로를 보는 참고입력 진단**이다. 이 수치를 실제 서비스의 개선 성능으로 보고하지 않는다.

| 진단, 4,872조건의 오답 수 | Pooled | Self+CLS |
|---|---:|---:|
| 실제 모델 | 718 | 770 |
| query만 원본으로 교체 | 693 | 770: query가 원래 동일 |
| attention가중치 전체를 원본으로 교체 | 630 | 602 |
| 원본가중치로 고친 기존 오답 | 203 | 224 |
| 원본가중치 때문에 새로 생긴 오답 | 115 | 56 |

해석:

- Pooled의 q만 복구하면86건을 고치지만61건을 새로 틀려 순25건 감소다. 전체 문제를 평균query의 소음오염 하나로 설명하기 어렵다. key/value와CNN특징 변화도 남는다.
- attention가중치 교체는 Pooled에서순88건, Self에서순168건을 줄였다. 따라서 어떤 가중치를 사용하는지가 실제 예측에 영향을 줬다는 근거는 있다.
- 하지만 교체 후에도630/602건의 오답이 남았다. 이 숫자를 단순히 CNN이 원인인 오답 수라고 해석하면 안 된다. 원본가중치도 항상 최적은 아니고, 가중치와value의 상호작용이 있으며, 원본부터 틀리는 경우도 있다.
- 원본은 맞고 소음에서는 틀린 경우에 한정하면 Pooled는467건 중195건, Self는576건 중211건을 원본가중치로 고쳤다. 나머지에는 가중치 교체만으로 충분하지 않았다.

## 5. attention분포의 변화도 오류와 관련됐지만 인과를 단정하지 않음

원본/소음 attention분포의 Jensen–Shannon divergence 중앙값은 Pooled 정답0.077/오답0.351, Self 정답0.048/오답0.133이었다. 오답에서 가중치 분포가 더 많이 바뀌는 경향이 있었다.

오답에서는 attention엔트로피도 더 높았다. Pooled 정답0.208/오답0.376, Self 정답0.477/오답0.545다. 엔트로피는 최대값으로 정규화했다. 이는 이 표본에서 오답일 때 가중치가 더 퍼지는 경향이며, attention이 퍼지면 항상 나쁘거나 낮은엔트로피가 좋은설계라는 뜻은 아니다. 어려운 소음이 특징과가중치를 함께 바꿀 수 있다.

## 6. 지금 연결할 수 있는 결론

1. 평균 풀링의 약점은 선택가중치의불안정성보다, CNN이 만든 단어단서가 잡음에도 평균에 살아남는지에 있다.
2. Pooled는 구별단서를 강조할 수 있지만 query/key/value가 모두입력특징에 의존한다. q만 보완하면 해결된다는 가설은 이번진단에서 충분하지 않았다.
3. 현재1블록 Self+CLS는 입력평균query가 아니라 공통학습query로읽는다. 이 모델의오류는 소음에따른key/value·가중치변화와 원본부터틀리는특징/분류경계를 나누어봐야 한다.
4. 소음+화자 대조는 두모델의서로다른오류를 줄이고 늘렸다. 같은단어를가깝게만드는것과 헷갈리는다른단어의단서를지키는것을 함께검증해야 한다.

이 결론은 현재 화자03·seed42·선택checkpoint의 분석이다. 학습 후CNN가중치가다르고 선택epoch도달라 모델구조하나의우월성을증명하지않는다. attention가중치는 음소정렬이나충분한설명이아니며, 이 분석은 실제 음절의 잘림/가청성을 검증하지 않았다.
