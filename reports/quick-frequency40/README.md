# 40분 제한 구조 가설 예비 실험 완료

준비부터 종료까지 **26.81분**,6조건 모두300epoch 및 최종 평가 완료. Pooled 하나/화자03/seed42/동일 증강/CE+0.1SupCon.
학습률은1000epoch cosine 일정의 첫300epoch다. checkpoint는0dB draw0 최고점으로 선택하고 표는원본 및8소음×3draw 평가다.

## 해석

- 소형2D 축 분리형이 예비 비교에서 가장 유망하다. 기존8채널 대비0dB F1+2.69%p, 명령어F1+3.16%p, 원본F1+2.79%p였다. 다만 잡음단독 오반응26.25%는 여전히 높다.
- 축 분리형은3×3 두 층을5×1 및1×3으로 바꿨다. 축 분리 외에 추가 시간 support가4→2프레임으로 줄고 파라미터도80개 줄었으므로 순수 축 분리 효과라고 단정하지 않는다.
- 폭16채널은 전체F1을 개선하지 못했다. 명령어F1은84.61→84.43%로 비슷했고 silence F1이77.50→58.95%로 낮아졌다. 한편 잡음단독 오반응은28.13→13.96%로 감소했다. 단순 용량 부족 가설을 지지하는 결과는 얻지 못했지만 모든 지표가 악화된 것도 아니다.
- 주파수2구역 보존은 세로CNN 대조군보다0dB F1+1.04%p, 명령어F1+0.83%p였다. 비슷한 추가 용량의 MLP 대조군은오히려0dB F1-2.10%p였다. 주파수 위치 보존 가설을 일부 지지하지만 한 화자·한 seed이며, 두 변경의 함수 구조/학습 난이도도 다르므로 원인 확정은 아니다.
- 두 기준 조건의매epoch draw0 F1은 기존1000epoch 실행의첫300epoch 기록과 정확히 일치했다. 전체6조건의1800개 증강trace hash도 일치한다.
- 이 결과를 기존1000epoch 최고점과 동일 예산 비교로 취급하지 않는다. 검출기 적용 후 순위나 여성화자 일반화를 보장하지 않는다.

후속 학습은 이 확인 과정에서 시작하지 않았다. 우선 소형2D 축 분리형을 장기 확인 후보로 남긴다.
