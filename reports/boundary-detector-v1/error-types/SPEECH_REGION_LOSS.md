# 정답 발화 구간 내부의 누락 비율

선택된 최고 체크포인트 TCN60 / CNN-GRU109를 유지한다. 기본 decode, 추가 crop margin 없음. 시간 기준 손실이며 음소·정보 손실을 직접 측정한 값은 아니다.

정의: `손실률 = |정답 발화 구간 - 예측 구간들의 합집합| / |정답 발화 구간|`.

여러 예측의 겹친 시간은 중복 합산하지 않고, 발화와 겹치는 모든 예측을 포함한다. 정답 밖의 과다 포함·별도 오검출은 이 지표에서 벌점이 없다. 정답 발화와 겹치는 예측이 없으면 손실100%다. 전체 집계는 누락 시간 합 / 정답 발화 시간 합이며 파일별 비율 평균·중앙값·분위수도 CSV에 따로 기록했다. 모든 예측을 보존한 상태의 평가로, 한 구간만 선택하는 최종 crop 정책의 손실률은 아니다.

| 조건 | TCN 손실률 | CNN-GRU 손실률 |
|---|---:|---:|
| 원본 | 4.59% | 4.41% |
| 10dB | 7.03% | 9.33% |
| 5dB | 9.52% | 12.35% |
| 0dB | 17.21% | 19.84% |

원본200개 정답 발화 총105.29초, 8소음 조건은 같은200개×8로 총842.32초다. 0dB에서 TCN144.99초, GRU167.16초를 놓쳤다. 평균 발화526ms에 대해 평균 누락91ms /104ms에 해당한다.

완전 누락은 앞·뒤에 이중 계산하지 않고 별도 항목으로 둔다. 앞부분/뒷부분은 겹치는 예측의 첫 시점/마지막 시점 바깥의 누락이다.

파일별 손실률 중앙값은 TCN12.04%, GRU14.99%. 손실률90분위는37.98% /42.41%. 손실25% 초과 파일은353/1600 /404/1600으로, 평균만 나쁜 소수 사례에 끌리는 것은 아니다.
