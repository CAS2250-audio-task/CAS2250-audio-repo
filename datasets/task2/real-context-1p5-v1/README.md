# 원본 주변 녹음을 보존한 1.5초 데이터

전체 1015개, mono PCM16 / 16 kHz / 24,000샘플입니다.

원본이 충분한 665개는 검수 구간 전체를 포함한 원본 연속 1.5초를 사용했습니다.
짧은 350개는 원본 전체를 사용하고 부족한 길이만 좌우 0값 패딩으로 채웠습니다. 홀수 패딩은 오른쪽에 한 샘플 더 넣습니다.

원본·기존 검수본·라벨·화자·split은 보존했습니다. 배경음 반복, 속도 변환, 잡음 증강은 적용하지 않았습니다. 기존 gain을 유지하되 새 주변음 때문에 피크 상한 -1 dBFS를 넘으면 전체 gain을 낮추고 review_required에 기록했습니다. silence는 gain 0 dB를 유지했습니다.

자동 파일 검증은 완료했으며 새 주변음의 청취 검수는 아직 하지 않았습니다. preprocessing_recipe.csv에 원본 해시, 구간, 패딩, gain과 출력 해시가 있습니다.
