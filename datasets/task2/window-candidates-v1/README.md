# 긴 8개 녹음의 1.5초 윈도우 후보

8개 파일에 대해 **39개 후보**를 만들었습니다. 모든 WAV는 mono 16 kHz, PCM16, 정확히 1.5초입니다.
기존 보류 처리본에서 연속 구간을 추출해 기존 증폭량을 유지합니다.

`audio/<단어>/<파일명>_w01.wav`의 `w01`은 해당 파일의 후보 1입니다.
`windows.csv`에 원본 자르기 시각, 기존 처리본 내 샘플 범위, VAD 구간별 포함 길이와 SHA-256이 있습니다.
`selections.csv`의 `window_number`는 사용자의 선택 전까지 비워 둡니다.
후보들은 직접 학습에 등록하지 않고 원본마다 최종 후보 하나만 사용합니다.

청취 페이지와 전체 연속 재생 파일은 로컬 `processed_datasets/manual-review/windows-1p5-v1/`에 있습니다.
선택 및 학습 절차는 [규격화 안내](../fixed-1p5-v1/README.md)를 참고하세요.
