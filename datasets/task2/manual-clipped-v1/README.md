# 수동 확정 음성 1,000쌍 (2026-11-16)

사용자가 클리핑 작업대에서 전체 1,000개를 확정한 뒤 내보낸 결과입니다.
5명 × 10단어 × 단어당 20개이며 silence는 포함하지 않습니다.
모든 WAV는 **16 kHz · mono · PCM16**, 길이는 가변입니다.

| 경로 | 내용 |
|---|---|
| `clips/화자/단어/ID.wav` | 최종 발화 클립 1,000개 |
| `trimmed_originals/화자/단어/ID_original.wav` | 원본 앞뒤 정리 범위를 적용한 비교용 음성 1,000개 |
| `clipping_ranges_1000.csv` | 지정 원본 기준 발화·출력·원본 정리 시각 |
| `clipping_work_backup.json` | 동일 데이터셋 작업대에서 복원할 수 있는 설정 백업 |
| `file_index.csv` | ID별 실제 파일 경로, 화자·단어, 지정 원본 해시 |
| `validation.json` | 개수·시각·파형 검증 결과 및 업로드 파일 해시 |

원본 앞뒤 정리를 변경한 파일은 **22개**입니다. 나머지 978개도 같은 WAV 형식으로 내보냈습니다.
정리 원본은 입력 녹음 파일의 바이트 사본이 아니라 지정 원본을 16 kHz mono로 변환해
사용자가 정한 범위만 남긴 파일입니다. 최환준의 지정 원본은 잡음제거본,
강재훈은 발화 밖 딸깍음 보정 사본이며, 나머지 세 명은 녹음 원본을 사용했습니다.

## 시각과 여유

CSV의 `source_trim_*`, `speech_*`, `output_*` 시각 단위는 초입니다.
기준 0초는 **앞뒤 정리 전 지정 원본의 시작**입니다.
`*_in_trimmed_s`는 이 폴더의 정리 원본 WAV 시작을 기준으로 한 상대 시각입니다.
따라서 정리 원본에 클립 위치를 표시할 때는 `output_start_in_trimmed_s`와
`output_end_in_trimmed_s`를 사용합니다.

출력은 발화 시작·끝 바깥의 실제 원본 샘플을 앞뒤 각각 30ms 포함합니다.
정리 원본 경계를 넘으면 해당 경계로 제한되므로 실제 여유는 `actual_*_margin_ms`로 확인합니다.
무음 추가, 1.5초 길이 고정, 학습용 padding은 적용하지 않았습니다.

## 확인 및 사용

모든 ID와 CSV·백업의 시각 일치, 2,000개 WAV의 형식·길이를 확인했습니다.
각 클립의 PCM 샘플이 대응 정리 원본의 해당 구간과 일치하는지도 확인했습니다
(시간을 샘플로 변환하는 반올림 차이는 최대 1샘플).
`confirmed`는 사용자가 작업대에서 확정한 상태를 기록한 값입니다.

이 버전은 데이터 전달용이며 학습 split이나 silence를 새로 배정하지 않았습니다.
기존 `raw-v1`, baseline 설정은 유지됩니다. 학습에 사용하려면 별도 metadata에서
이 폴더의 WAV 경로를 지정하고 화자 단위 split과 silence 구성을 정하세요.
